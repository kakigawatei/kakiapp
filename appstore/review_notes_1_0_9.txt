[Version 1.0.9 — build 23]

This is a small fix. The once-a-day features (daily roulette, visit gacha, login bonus, visit record) previously used the device clock to decide "today", so a user could change the phone's date to use them repeatedly. They now use the server time (Firestore's response timestamp) converted to Japan time. If the server time cannot be fetched (offline), the action is not performed and a short message asks the user to try again with a connection. The day now changes at midnight Japan time instead of 9:00 a.m.

No new permissions, no new data collection, no UI changes other than that message.
