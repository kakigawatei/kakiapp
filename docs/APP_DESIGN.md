# 柿川亭アプリ 設計書（たたき台 v1 / 2026-08-26）

リピート・集客のためのポイント＆ガチャアプリ。探検録で実証済みの型（PWA + Firebase）で作る。

## 1. コンセプト

- 名称: **柿川亭アプリ**（正式ロゴ・アイコンはfal GPT Image 2で制作）
- 目的: ①再来店の動機づけ ②メールリスト獲得 ③SNS露出 ④通販・グッズへの送客
- 気持ちよさ最優先: ルーレット・ガチャの「激アツ演出」（fal H3で動画生成）で毎日開きたくなるアプリに

## 2. 通貨設計（v1.1で単一通貨に簡素化・masa決定 2026-08-26）

- 通貨は**ポイント(P)1本**。**1P = 1円換算**（例: **850P = 油そば並盛**）
- 入口の格差で「来店が一番おいしい」を表現:
  - **来店ガチャ**（各席のQRから・1日1回）: **10P/30P/50P/100P・ハズレなし**
    - 確率: **10P=80%／30P=10%／50P=7%／100P=3%**（期待値 17.5P/来店）
  - ログインボーナス・毎日ルーレット・ミッション: 小口のP（数値は運用しながら調整）
- 使い方は**PayPay方式**: 会計時に自分で使用ポイント数を入力→スタッフの目の前で「使用」→スタッフ確認で消込。端数利用OK（850P貯めて1杯でも、100Pだけ値引きでも）
- 🔒 Pは**無償付与のみ**（現金販売しない）→ 資金決済法の届出不要を維持
- 確率・付与量はすべてサーバー側の設定値にして、ノーリリースで調整できるようにする

## 3. 来店ログとランク制度

- チェックインするたびに `visits[]` に日付を記録（1日1回まで）
- **累計来店数でランクアップ**。ランクは常時表示して誇れるように

| ランク案 | 来店数 | 特典案 |
|---|---|---|
| 油そば見習い | 0〜4回 | - |
| 常連 | 5回〜 | ルーレット結果 1.2倍 |
| 猛者 | 15回〜 | ガチャ排出率アップ |
| 油神(あぶらがみ) | 40回〜 | 限定グッズ交換解禁・裏メニュー(?) |

※ランク名・境界・特典はmasaと詰める（柿川亭らしい言葉に）

## 4. 機能一覧（MVP→拡張）

### MVP（フェーズ1）
1. **会員登録**: メールアドレス認証（Firebase Auth）。利用規約に販促メール利用の同意を明記＝リスト獲得
2. **ホーム**: 残P/C・ランク・今日のルーレット/チェックイン状況
3. **来店ガチャ**: **各席に設置したQR**（日替わりコード）を読み取り→ガチャ演出→10〜100P獲得＋来店ログ記録。1日1回
4. **毎日ルーレット**: 1日1回（来店不要）。小口P獲得。H3動画演出（通常/激アツの2パターン以上）
5. **ポイント支払い（PayPay方式）**: 会計時に使用P数を自分で入力→確認画面をスタッフに見せる→**スタッフが確認ボタンをタップ**して消込
6. **管理画面**: 使用履歴・付与統計・QRコード日替わり管理

### フェーズ2
8. **ミッション**: SNSフォロー・キャンペーン投稿（**#PR表記の案内文つき**）・アンケート回答→P付与
9. **通販連携**: C消費→Stripeクーポンコード自動発行
10. **グッズ交換**: C消費→店頭受け取り予約
11. **プッシュ的お知らせ**: 探検録のannouncements方式（Firestore＋🔔）

## 5. 法規制ガードレール（設計に織り込み済み）

- ❌ Google口コミへの対価はやらない（GBP停止リスク）→ ミッションは来店/フォロー/アンケートで代替
- SNS投稿ミッションは応募案内に「#PR」等の表記指示を含める（ステマ規制対応）
- ガチャ経由の景品は景表法「懸賞」: **取引価額の20倍以内・総額は売上予定総額の2%以内**。景品単価表を作って上限管理（トッピング券100〜200円・油そば1杯900円前後なら余裕）
- 来店チェックインの直接付与（偶然性なし）は総付景品/自社ポイント扱いでさらに安全
- プライバシーポリシー: メールの利用目的（お知らせ・販促）を明記

## 6. 不正対策

- メール認証必須＋同一端末の複数アカウント検知（端末フィンガープリント）
- チェックインQRは日替わりコード（前日のスクショ無効）＋1日1回制限
- ルーレット/ガチャ/引き換えはすべてサーバー側（Firestoreルール＋Cloud Functions or セキュリティルール）で検証
- 目立つ不正が出たら電話番号(SMS)認証を追加する二段構え

## 7. 技術構成

- **PWA**（ホーム画面に追加・インストール不要）。ホスティングはGitHub Pages（shime-app方式）または kakigawatei.com 配下
- **Firebase**: Auth（メール認証）／Firestore（users・visits・redemptions・missions・gacha_log）／必要ならFunctions
- **演出素材**: 絵柄=fal GPT Image 2、ルーレット・ガチャ動画=fal H3（1本約100円・事前生成してアプリに同梱）
- **通販**: Stripeクーポン API
- データ設計（初案）:
  - `users/{uid}`: email, points, coins, rank, visitCount, createdAt
  - `users/{uid}/visits/{date}`: checkinAt, qrCode
  - `redemptions/{id}`: uid, item, coins, staffConfirmedAt
  - `daily/{uid}_{date}`: roulette済/checkin済フラグ
