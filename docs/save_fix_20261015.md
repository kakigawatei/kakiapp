# 保存の失敗対策（auth.js）2026-10-15

masa 承認「入れて」。build・ストア提出・git push・Firestore 書き込み・ルール公開は**まだしていない**（手元で作って点検まで）。

## 何があったか
- 10/15 夜まで、Firestore ルールが 1000 式の上限に当たり、来店などの保存が全部拒否されていた（ルールは 21:54 に直して公開済み・`docs/firestore_rules_2026-10-15_fix.txt`）
- アプリ側の穴 1: `cloudPush` が `write().catch(() => {})` で失敗を捨てていた。起動時の `pull()` がクラウドで上書きするので、保存に失敗した「今日回した」印が消え、**開き直すと同じ日にもう一度回せた**（点検で直す前の auth.js でも再現: 「拒否後に開き直して回せる=true／知らせ0回／__errs 0件」）
- アプリ側の穴 2: 履歴 tx の和集合が `JSON.stringify(t)` で比べていたため、項目の並び順が違う同じ履歴を別物とみなし重複が増えた（10/14〜 36人・1,689件）

## 変えたこと（auth.js の `SYNC-CORE-BEGIN`〜`END` の区間＋2か所）
1. **失敗を見えるように**: 失敗は `window.__errs` に記録（開発モードの「エラーを見る」に出る）。利用者には画面下に短い知らせを**1回の起動で種類ごとに1回だけ**（7秒で消える・タップで消える）
   - 通信の失敗（unavailable／timeout など）: 3秒→10秒→30秒の3回まで再試行し、それでもだめなら「電波の良い所でアプリを開き直してください（この端末には残っています）」
   - 拒否（permission-denied）: 再試行しない。「時間をおいてアプリを開き直してください（この端末には残っています）」
2. **未保存の控え（localStorage `kakiapp_pending`）**: 端末で変更が起きたら控えを付け、クラウドに保存できたら消す
   - 起動時に控えがあり、端末の1日1回もの（ルーレット・来店ガチャ・ログボ・チェックイン・投稿・学校の来店日）が「今日」の分なら、**クラウドで上書きせず端末を残して送り直す**＝同じ日にもう一度取れない
   - そのときクラウド側が新しいもの（別端末の今日の印・運営の加算・受け取り済みの印・来店・履歴）は取り込み、ポイントは差分マージ（運営の加算も端末の増分も両方残る）
   - 控えが**昨日以前**の分なら、ルール（日付は今日にしか書けない）上もう送れないので**クラウドを正に戻す**（＝その日の未保存分は失われる。従来どおり）。戻したことは `__errs` に残す
   - 「時間切れ扱いだったが実は届いていた」保存を `updatedAt` で見分け、再試行で二重に足さない
3. **tx の重複**: d／label／points で同じものとみなす（並び順に依らない）。和集合のたびに重複を除き新しい順に並べる。起動時にクラウドの履歴に重複があれば、その起動の保存で整える。**ポイント残高は変えない**
4. その他: ログアウト・データ削除で控えも消す。`kakiStart()` の直後に `afterReady()`（控えの送り直し・履歴の整理）を呼ぶ

### 「クラウドに保存できるまで確定しない」案を採らなかった理由
- 店内は電波が悪いことがある。保存の確認まで回せない／ガチャ結果を出さない形にすると、**店で来店ガチャが回せない**・演出が止まる、の方が体験を壊す
- 今の形（端末で先に確定 → 控えを残して必ず送り直す）なら、電波が悪くても回せて、同じ日の二重取りは端末側で止まり、クラウド側はルール（日付は今日だけ・増分の上限）が守る

## 危険・残る穴
- **日付をまたいだ未保存は失われる**（23:59 に回して保存が 0:00 以降になる等）。ルールが昨日の日付を拒否するため。直すにはルール側の変更が必要
- 拒否が続く日は端末だけにポイントが見えて、翌日の起動でクラウドの値に戻る（「ポイントが減った」に見える可能性）
- 端末を2台使っていて、両方で未保存がある等の重なりは、受け取り済みの印が2件以上同時に増えるとルール（1回に1件）で拒否されうる（従来からある）
- 控えのある間はクラウドより端末を優先するので、管理画面でクラウドの日付の印を手で消しても、その端末では今日中は戻らない
- 画面の知らせは auth.js が自前で出す簡単な帯（index.html の見た目に合わせていない）。`window.kakiNotice(text)` を本体に作れば差し替わる
